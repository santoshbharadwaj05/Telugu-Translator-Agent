# English → Telugu Agent

A small web page that translates English into Telugu.

**Live site:** https://santoshbharadwaj05.github.io/Telugu-Translator-Agent/

## Run locally

Open `index.html` in a browser, or from this folder run:

```powershell
python -m http.server 8000
```

Then visit http://localhost:8000

Type English, click **Translate** (or press Ctrl+Enter). The agent replies in Telugu.

Uses the free [MyMemory](https://mymemory.translated.net/) API. No API key is required.
